# SEO Crawl Audit 0.16.1

This patch fixes three defects reproduced while auditing pass-gen.app with the published 0.16.0 package.

The crawler now honors the first `<base href>` for relative canonical, hreflang and anchor URLs in both HTTP and rendered HTML. Relative links also use the actual response directory before crawl URL normalization, including after redirects. Invalid or browser-ignored base values retain the response URL as the fallback.

Repeated generic `meta name="robots"` values are combined, so a later `noindex` directive is visible in snapshots, audit findings and indexability summaries.

The optional Playwright renderer resolves a project-installed peer when the CLI runs from an npx cache or global prefix. Package-local installations remain supported, and missing Chromium retains its separate installation guidance.

README scope now distinguishes supported HTTP-header authentication from unsupported interactive login/session workflows. SnapshotV2 and rule set 1.2.0 are unchanged. Previously saved snapshots retain their original extraction; re-scan affected pages to apply these fixes.
