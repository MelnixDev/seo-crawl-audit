# SEO Crawl Audit 0.14.0

Release candidate; publication is pending.

Compare two saved runs of the same site in the local UI without making new page
requests. The comparison runs in a worker and produces a standalone HTML report,
plus concise Markdown and CSV summaries. Coverage is explicit: findings are not
called resolved when the current run did not collect enough evidence. Changes
can be grouped by rule and URL template.

The history catalogue uses stable run IDs and bounded listing. Failed or
cancelled comparisons do not replace the last completed comparison. A completed
artifact survives a local UI restart. MCP same-site comparisons now include an
additive summary; cross-site comparisons keep their existing behavior.

SnapshotV2, issue fingerprints, existing CLI commands and exit codes remain
compatible. All comparison data stays local. Multi-run trend drill-down remains
deferred; this release compares one selected pair at a time.

Validation before publication: full check, packed-package test, production npm
audit, local browser QA, and 50,000-page/issue performance tests. Remote CI and
release publication must pass separately before this candidate is called live.
