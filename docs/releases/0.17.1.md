# SEO Crawl Audit 0.17.1

## Codex plugin startup fix

The 0.17.0 setup wrote an absolute Node executable in the portable MCP command. Actual Codex native loading rejects that form, so a plugin could install and show its skill while its MCP server never appeared. This patch keeps the allowed bare `node` command and binds executable lookup through the per-server PATH recorded by setup. It changes no global PATH and does not install a runtime. Rerun setup and reinstall/refresh the configured local plugin after upgrading, or after moving Node.

A native Codex CLI/app-server regression test imports the marketplace, discovers all eight tools and executes a bounded fixture scan with an empty inherited PATH. This is separate from a standalone MCP launch.

## Crab identity and product website

Production-size 512px icons preserve the unchanged full-resolution master without duplicating it in each native archive. A shared crab logo ships in Codex plugin/skill metadata, Claude Desktop MCPB and Claude Code directory metadata. Claude Code may ignore directory icons in its local runtime. No actual client GUI rendering, public marketplace approval or endorsement is claimed. The Desktop MCPB remains unsigned.

The public website introduces the crawler, client setup, real controlled-fixture screenshots and a report walkthrough. It contains no customer site captures, credentials or personal workspace paths. Existing example report content is preserved under `/demo/` and `/report.html`.
