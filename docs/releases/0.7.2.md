# SEO Crawl Audit 0.7.2

Version 0.7.2 is a documentation and release-hygiene patch. It publishes the
full-resolution report screenshots in the npm README and makes the current
distribution boundary explicit.

Highlights:

- original PNG captures for the overview, analytics, and issue-table previews;
- matching screenshot references in the repository and npm README;
- an explicit note that `@seo-crawl-audit/core` remains an unpublished workspace
  package while the self-contained `seo-crawl-audit` CLI is the supported npm
  distribution;
- completed changelog entries for the 0.7 release line.

Compatibility:

- no crawler, audit, CLI, Action, or report behavior changes;
- SnapshotV2, rule IDs, fingerprints, rule-set version `1.1.0`, commands, flags,
  outputs, and normal exit codes remain unchanged;
- no cloud service, telemetry, account, billing, or paid functionality is added;
- `@seo-crawl-audit/action` remains private on npm and is distributed through
  GitHub tags only.
