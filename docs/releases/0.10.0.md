# SEO Crawl Audit 0.10.0

Version 0.10.0 improves the free, local-first user experience without changing
SnapshotV2, existing rule IDs, or issue fingerprints.

## Highlights

- run scans from a loopback-only browser interface with live progress and
  embedded local reports;
- review grouped site metrics, crawl and sitemap coverage, HTTP status
  distribution, local scan history, and optional public RDAP domain data;
- opt into Playwright rendering for JavaScript-dependent pages while the fast
  HTTP crawler remains the default;
- inspect resumable checkpoints and get clearer planning, retry, cancellation,
  and completion feedback from CLI scans;
- use improved English and Ukrainian report labels, self-contained branding,
  and favicon support;
- see explicit MCP server readiness while retaining compatibility with clients
  that read tool payloads from standard text content.

## Compatibility and privacy

The release preserves existing CLI commands and flags, SnapshotV2, rule IDs,
fingerprints, rule-set version `1.1.0`, JSON outputs, and local HTML reports.
It does not add cloud services, telemetry, accounts, billing, or paid features.

Only the `seo-crawl-audit` CLI package is published to npm. Core, Action, and
MCP workspace packages remain internal; the MCP server is bundled into the CLI,
and the GitHub Action is distributed through repository tags.
