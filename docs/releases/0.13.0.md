# SEO Crawl Audit 0.13.0

Release candidate; publication is pending.

The Pages view now shows observed inlinks and their source URLs. Find pages
linking to checked errors or redirects, inspect their targets, filter by depth
or inferred URL template, and export the matching page data as CSV.

Counts come only from the saved crawl. Unchecked targets are not classified as
broken, and zero observed sources does not prove that a page is isolated.
SnapshotV2, issue fingerprints, and existing CLI contracts remain compatible.

Validation: 157 tests in both coverage runs, packed-package checks, Chromium
navigation/filter/CSV checks, and a 50,000-page/issue browser benchmark.
