# SEO Crawl Audit 0.14.1

Published on GitHub and npm.

Self-contained comparison reports now store repeated issue fields in a compact
internal payload. The public `ReportData` input and visible report features are
unchanged: evidence, remediation, EN/UK text, filters, Pages ↔ Issues links,
printing, and CSV exports remain available offline.

The synthetic 50,000-page comparison decreased from approximately 171 MiB to
66 MiB HTML. On the release test machine (darwin-arm64, Node 24.8.0,
Chromium 153), sampled peak heap was 716 MiB, sampled RSS 1190 MiB,
browser load 1023 ms, filtering 43 ms, and opening page details 3 ms.
Sampling can miss peaks during synchronous work, and real sites may differ.

SnapshotV2, fingerprints, CLI flags and exit codes remain compatible. The
GitHub Action `v0` moving tag is not changed by this release.
