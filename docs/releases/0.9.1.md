# SEO Crawl Audit 0.9.1

Version 0.9.1 is a compatibility and observability patch release for the
free, local-first CLI and MCP workflows.

## Changes

- MCP tool results keep their complete JSON payload in `content[].text` for
  clients that do not consistently support `structuredContent`;
- CLI scans now show planning, robots, sitemap, crawl, retry, resume, and
  cancellation status;
- `--json` keeps stdout machine-readable while progress is written to stderr;
- existing commands, flags, snapshots, issue IDs, and report formats remain
  compatible.

The release does not add cloud services, telemetry, accounts, or paid
features. The CLI remains the only publishable workspace package.
