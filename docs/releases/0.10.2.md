# SEO Crawl Audit 0.10.2

Version 0.10.2 makes the local browser workflow clearer by separating optional
public metrics from the main SEO crawl.

## Highlights

- `Start SEO scan` now performs only the local page crawl and audit;
- `Update public metrics` collects Google `site:` and RDAP data separately;
- public metrics reuse the latest SnapshotV2 and do not crawl pages again;
- manual Google estimates remain available when the public result count is
  hidden;
- roadmap and handoff documentation now match the shipped product.

All artifacts remain local, and no telemetry or hosted account is introduced.
