# SEO Crawl Audit 0.16.0

Exact duplicate titles across successful indexable/self-canonical pages now produce critical errors. Intentional noindex/canonical variants remain review warnings. A dedicated `pagination-title-duplicate` error identifies first/later query pages sharing a title, with concrete URL evidence and developer remediation.

The Drupal regression case: `?page=1` served page 2 with a correct self canonical but reused page 1 title. Add a readable page number without hiding valid pagination behind noindex or a page-1 canonical.

`near-duplicate-title` is a warning for bounded punctuation/one-token similarity of long titles; it does not flag properly differentiated pagination or claim semantic equivalence. Both new rules skip nonindexable/failed responses.

Rule set 1.2.0 includes the severity change. Existing severity overrides and suppressions still apply. The CLI/npm distribution boundary and SnapshotV2 remain unchanged. The GitHub Action `v0` tag is not moved by this release.

Use a targeted collection crawl with `--no-sitemap --include-query` and inspect checked URLs: a sitemap-only sample can miss pagination. These are critical risks, not evidence that Google excluded a page for a particular reason; inspect Search Console's reason and chosen canonical.

Compatible production dependency updates clear the current npm advisories. Full MCP identifier minification keeps the updated SDK bundle within the existing 1.5 MiB package budget; stdio integration tests cover initialization and tool discovery.
