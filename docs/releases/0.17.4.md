# SEO Crawl Audit 0.17.4

This maintenance release fixes #42: non-interactive scans now honor the resolved config/baseline page budget instead of substituting a 100-page sitemap limit. A configured budget below 100 is not exceeded and one above 100 is not silently reduced. Explicit `--pages N`, `--max-pages N`, intentional `--all` and interactive selection retain their override behavior. Without a configured or saved limit the safe default remains 100.

The Ukrainian estimated-indexable-pages label now says “Орієнтовна кількість сторінок, доступних для індексації” (#37). English wording and the existing disclaimer distinguish observed crawlability from a verified Google index count. The new text was inspected in a standalone report and a local-UI-generated report at mobile width.

The historical navigation overflow in #36 is not reproduced with the existing flex-wrap layout: EN/UK Issues views at 320, 375 and 390 CSS pixels keep document width within the viewport; tables retain their own scroll container and keyboard focus remains visible. No extra CSS patch or new visual design is claimed.

Validation includes real bundled-CLI subprocesses with config limits 2/120, explicit upward/downward page overrides, default 100 and intentional all 150 URLs; assertions cover actual HTML requests, snapshot limits and partial/truncated scope. The installed CLI tarball has its own config-budget regression in package contracts. Required gates remain lint/build, core/app coverage, package/native contracts and the OS/Node CI matrix.

Distributions are npm `seo-crawl-audit@0.17.4`, versioned GitHub Action, native Codex/Claude Code ZIP and Claude Desktop MCPB with SHA-256 checksums. Moving `v0` is unchanged. Interactive client GUI installation remains unverified (#43). Non-TTY heartbeat lifecycle (#38), optional semantic structured-data validation (#39) and configurable locale-path validation (#40) remain open and are not claimed fixed. No Balachky production audit or site changes are included.
