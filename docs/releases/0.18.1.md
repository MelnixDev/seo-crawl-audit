# SEO Crawl Audit 0.18.1

This release refines three checks found during a production SEO audit.

- The title length rule checks indexable pages. Separate noindex findings still show where the directive is present.
- Fuzzy title similarity skips translations when the documents declare different languages and link to each other with matching hreflang. The exact duplicate and pagination rules still apply.
- Word count and duplicate text fingerprints use the visible body text. Editing the document title alone no longer changes either value.

The rule set advances to 1.4.0. Saved snapshots keep their original word counts and text fingerprints. Crawl again to use the new extraction and account for the rule change when comparing results across releases.
