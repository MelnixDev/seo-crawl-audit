# SEO Crawl Audit 0.6.0

Version 0.6.0 is an architecture and reliability release. It does not add SEO
checks or change existing rule IDs and fingerprints.

Highlights:

- reusable `planScan()` and `scan()` public APIs;
- deterministic breadth-first crawling at any supported concurrency;
- durable typed checkpoints and Node.js file adapters in `core/node`;
- coverage-aware partial comparisons through `DiffResult.complete`;
- graceful CLI interruption with saved partial outputs and exit code `130`;
- a stable root export whitelist and strict TypeScript boundaries;
- a testable GitHub Action runner with unchanged inputs and outputs;
- clean packed-package, coverage, 10k-page, and cross-platform quality gates.

Compatibility is preserved for SnapshotV2, automatic SnapshotV1 migration,
configuration precedence, CLI commands and flags, normal exit codes, report
formats, and current issue fingerprints.

The GitHub Action continues to run entirely in the GitHub runner. After the
versioned release is verified, the moving `v0` tag should point to `v0.6.0`.
