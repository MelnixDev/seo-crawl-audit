# SEO Crawl Audit 0.17.3

This correctness release fixes [issue #32](https://github.com/MelnixDev/seo-crawl-audit/issues/32): the crawler no longer removes meaningful trailing slashes before requesting sitemap entries and discovered pages. The previous behavior could create synthetic sitemap redirects and hide real canonical-to-redirect mismatches.

`trailingSlash` defaults to `preserve`. Explicit `strip` traversal remains available through JSON config, `--trailing-slash strip` and MCP inputs; the Action uses the same config file. Observed final URLs, canonical targets and hreflang retain their actual paths/query independently of traversal policy. `canonical-target-redirect` is a warning backed by an actually checked target and requested/final/Location evidence. Redirect aliases do not become separate critical duplicate-title findings. A redirect alone is not proof of Google indexing exclusion.

Legacy snapshots remain readable as stripped/unknown observations; missing original URL paths are never reconstructed. New observation checkpoints cannot reuse old normalized page records. Configuration/checkpoint identity includes URL policy. Cross-policy comparisons are incomplete and do not claim resolutions or missing-page regressions caused only by changed URL keys; capture a fresh baseline under the intended policy. Rule set advances to 1.3.0; SnapshotV2 remains the container format.

Consumer distributions are npm `seo-crawl-audit@0.17.3`, native Codex/Claude Code ZIP, Claude Desktop MCPB with SHA-256 checksums, and the versioned Action `MelnixDev/seo-crawl-audit@v0.17.3`. Internal workspaces stay private; moving `v0` is unchanged. Native archives contain the same reviewed engine bundle. Update/reconfigure an installed native package to use the new engine; an existing running MCP session is not silently replaced.

Validation covers slash-required and slashless HTTP fixtures, genuine versus synthetic sitemap redirects, raw canonical mismatches, pagination, renderer output, robots, legacy snapshots/checkpoints and CLI/MCP policy. Required gates are lint/build, both coverage suites, standalone packed imports/types/CLI checks, native-package contracts, and the Linux/macOS/Windows Node 20/22/24 CI matrix. Interactive GUI installation remains unverified; the optional native-loader test can be skipped when its external runtime is unavailable.

The interface and visual media remain those documented for 0.17.2; this release does not claim fresh screenshots or new GUI acceptance. The known scan-budget issue #42 still requires explicit `--pages N` or intentional `--all`. No Balachky production changes, new site audit, storage automation or automatic data deletion are included.
