# SEO Crawl Audit 0.12.0

Version 0.12.0 adds a Page Explorer to the self-contained local report and
closes the remaining large-scan confirmation and Site Metrics safety gaps. It
does not add SEO rules or change SnapshotV2, issue fingerprints, CLI flags,
normal exit codes, or the rule-set version.

## Highlights

- Browse every checked URL, including pages without issues.
- Filter and sort by URL, HTTP status, observed crawl indexability, issues, and
  severity with 50, 100, or 250 rows per page.
- Inspect redirects, robots directives, canonical metadata, titles,
  descriptions, language, H1 count, word count, transfer size, depth, links,
  and page-level remediation in an accessible details panel.
- Navigate between a page and its exact issue set.
- Export every filtered page safely as CSV in English or Ukrainian.
- Keep large reports responsive with a compact page projection and visible-row
  rendering instead of creating DOM rows for the entire crawl.

## Safety and compatibility

The report never describes crawler observations as proof of Google indexing.
Large UI and MCP scans require confirmation bound to the exact URL and scan
parameters. Cached external metrics are origin-checked and source-allowlisted.
All crawling and report data remain local, with no telemetry, account, hosted
service, or paid feature.

The release was exercised with 50,000 pages and 50,000 issues in Chromium and
with a 100-page HTTP dogfood scan of an explicitly permitted site.
