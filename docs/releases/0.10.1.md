# SEO Crawl Audit 0.10.1

Version 0.10.1 improves the Site Metrics experience while preserving the
local-first crawl and audit workflow.

## Highlights

- adds a clearly labelled, low-confidence Google `site:` result estimate;
- provides a manual local fallback when Google hides the count behind consent
  or automated-request protection;
- keeps public estimates separate from authoritative Search Console coverage;
- estimates indexable pages from partial sitemap crawls without presenting the
  value as a Google index count;
- completes English and Ukrainian labels for estimate and availability states;
- prevents concurrent atomic snapshot and report writes from sharing a
  temporary filename.

No scan data is uploaded to SEO Crawl Audit servers. Optional public metrics
send only the audited hostname to the selected public provider.
