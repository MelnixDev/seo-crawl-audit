# SEO Crawl Audit 0.19.0

Run `npx seo-crawl-audit demo` to compare a fictional production storefront with a preview that introduces `noindex` on `/pricing`, then with the corrected preview. The same comparison engine used by `seo-audit compare` generates the failed and passing self-contained HTML reports. After npm downloads the package, the demo uses in-memory fixtures without website requests, project configuration, or a running server.

Pass `--no-open` to print the reports’ file paths, or `--directory <new-directory>` to keep both reports in a directory you choose. The demo returns success after it observes the expected fail-then-pass sequence.
