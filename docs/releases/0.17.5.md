# SEO Crawl Audit 0.17.5

The copyable audit prompt and packaged skill now start from the active project. Agents use an explicit user URL first, then inspect project instructions, audit/site/deployment configuration and documentation. An unambiguous target is announced with its supporting evidence and used without an unnecessary confirmation round. Missing or conflicting app, environment or URL details still require clarification before website requests.

A mismatched MCP workspace no longer stops an otherwise available project-local CLI workflow. Agents must keep artifacts in the current project and must not scan into another project or silently reconfigure a global plugin. Folder names, Git remotes, examples and dependency URLs are not sufficient target evidence.

This is an agent guidance update; crawler behavior and public APIs are unchanged. Native packages include the same updated skill as the CLI.
