# SEO Crawl Audit 0.15.0

Release candidate; publication is pending.

This release adds local issue trends across the latest 20 saved exact-site
scans, with explicit 50- and 100-run ranges. The loopback-only UI shows a
bilingual interactive chart, coverage/policy gaps, cancellable progress, and
links from points to the existing adjacent-run comparison. CLI `history --json`
adds a compact `trendSummary`, and MCP adds read-only `seo_audit_history`.

History analysis reads saved snapshots only. It makes no page requests and
does not change SnapshotV2, issue fingerprints, CLI exit codes, or the
standalone report format. A falling issue count is not presented as proof of
improvement when coverage or policy changed. The GitHub Action `v0` moving tag
remains unchanged.
