# SEO Crawl Audit 0.11.0

Version 0.11.0 scales the local-first product to safely handle sites with up to
50,000 pages. It does not add SEO rules or change SnapshotV2, existing issue
fingerprints, CLI flags, normal exit codes, or the rule-set version.

## Highlights

- Quick, Standard, Full sitemap, and Custom profiles in the local web UI.
- Preflight URL counts and explicit confirmation before scans above 5,000 URLs.
- MCP full-sitemap scans with the same confirmation contract and 50k ceiling.
- Durable disk-backed NDJSON page journals retained until final outputs are safe.
- External Site Metrics persisted separately from SnapshotV2 with stale labels.
- A maintainable bundled local UI without a separate frontend installation.
- Faster large reports with paginated rows, debounced search, and on-demand CSV.

## Safety and compatibility

HTTP remains the default renderer and Playwright remains opt-in. Full sitemap is
not available without a discovered sitemap, and robots, pacing, redirect, and
response-size protections stay enabled. All crawl data remains on the user's
machine, with no account, telemetry, cloud service, or paid feature.

The 50k fixture completes a full crawl, durable checkpoint journal, audit, and
self-contained report under the release limits. Cancelled scans keep their
journal for a compatible resume.
