# SEO Crawl Audit 0.7.1

Version 0.7.1 adds Ukrainian rule documentation to the bilingual local report.

Highlights:

- a complete Ukrainian reference for all 46 built-in and regression rules;
- stable rule anchors in both English and Ukrainian documentation;
- automatic Ukrainian documentation links when the report language is set to
  `Українська`;
- language links in the repository and npm README;
- a contract test that keeps both rule references aligned with the built-in
  registry.

Compatibility:

- SnapshotV2, rule IDs, fingerprints, and the rule-set version remain unchanged;
- existing CLI commands, options, outputs, and exit codes remain unchanged;
- no cloud service, telemetry, account, billing, or paid functionality is added;
- `@seo-crawl-audit/action` remains private on npm and is distributed through
  GitHub tags only.
