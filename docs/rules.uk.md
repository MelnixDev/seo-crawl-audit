# Правила SEO Crawl Audit

[English](rules.md) | **Українська**

Кожна знайдена проблема має стабільний ID правила, рівень критичності,
відповідального, докази, рекомендацію з виправлення та fingerprint. Правила
повідомляють про конкретні ризики; інструмент не обчислює загальний SEO-бал.

Рівні критичності:

- `error` — проблема, яка, ймовірно, перешкоджає обходу, індексації або доступу
  та блокує звичайну перевірку регресій;
- `warning` — важлива проблема SEO або якості контенту;
- `info` — корисна інформація, яку варто переглянути, але яка типово не блокує
  перевірку.

## Доступ, індексація та перенаправлення

### page-unreachable

Запит сторінки завершився невдало після обмеженої кількості повторних спроб.
Відповідальний: `developer`. Відновіть сторінку, виправте мережеву проблему або
приберіть посилання на URL, який свідомо виведено з експлуатації.

### http-error

Сторінка повернула HTTP 4xx або 5xx. Відповідальний: `developer`. Поверніть
успішну відповідь або налаштоване перенаправлення на чинну сторінку-заміну.

### robots-blocked

Сторінку заборонено відповідною групою правил у `robots.txt`. Відповідальний:
`developer`. Дозволяйте доступ лише тоді, коли пошукові роботи повинні обходити
цю сторінку.

### noindex

HTML містить meta-директиву `noindex`. Відповідальний: `seo`. В окремому аудиті
це інформаційне повідомлення, адже директива може бути навмисною.

### x-robots-noindex

HTTP-заголовок `X-Robots-Tag` містить `noindex`. Відповідальний: `developer`.
Переконайтеся, що заголовок додано навмисно; приберіть його, якщо сторінка має
індексуватися.

### redirect-loop

Ланцюжок перенаправлень повертається до вже відвіданого URL. Відповідальний:
`developer`. Розірвіть цикл і перенаправляйте одразу на кінцеву адресу.

### long-redirect-chain

Для переходу потрібно понад три перенаправлення. Відповідальний: `developer`.
Замініть проміжні переходи прямим перенаправленням.

### http-on-https-site

HTTPS-сайт містить внутрішній HTTP URL у результатах обходу або метаданих.
Відповідальний: `developer`. Послідовно використовуйте HTTPS.

## Канонічні URL

### missing-canonical

Канонічне посилання не знайдено. Відповідальний: `seo`. Додайте його, якщо
можуть існувати варіанти URL або дубльовані шляхи.

### invalid-canonical

Значення canonical неможливо перетворити на HTTP(S) URL. Відповідальний:
`developer`. Використайте чинний абсолютний URL або коректне відносне посилання.

### cross-domain-canonical

Canonical веде на інший origin. Відповідальний: `seo`. Переконайтеся, що таке
об’єднання між сайтами є навмисним.

### canonical-target-error

Ціль canonical входить до сканування, але недоступна. Відповідальний:
`developer`. Вкажіть успішну кінцеву сторінку, яку можна індексувати.

## Узгодженість sitemap

### sitemap-unavailable

Налаштований sitemap не вдалося завантажити або розібрати. Відповідальний:
`developer`. Відновіть доступний і коректний XML sitemap.

### noindex-in-sitemap

URL із sitemap позначено як `noindex`. Відповідальний: `seo`. Приберіть його із
sitemap або зробіть доступним для індексації.

### redirect-in-sitemap

URL із sitemap перенаправляє на іншу адресу. Відповідальний: `seo`. Додайте до
sitemap його кінцевий канонічний URL.

### orphan-sitemap-page

Сторінка із sitemap не має знайдених внутрішніх посилань. Відповідальний: `seo`.
Додайте корисну внутрішню навігацію або переконайтеся, що сторінку ізольовано
навмисно.

### crawlable-not-in-sitemap

Успішну доступну для обходу сторінку знайдено поза sitemap. Відповідальний:
`seo`. Додайте її до sitemap або свідомо виключіть.

### sitemap-url-count-drop

Порівняно з базою sitemap втратив щонайменше 20% і щонайменше п’ять URL.
Відповідальний: `seo`. Перевірте, чи немає випадкових виключень або помилок
генерування.

## Заголовки, описи та структура

### missing-title

Сторінка не має непорожнього HTML title. Відповідальний: `content`. Додайте
унікальний інформативний заголовок.

### duplicate-title

Кілька просканованих сторінок мають однаковий title. Відповідальний: `content`.
Розрізняйте сторінки відповідно до їхнього призначення.

### title-length

Title коротший за 10 або довший за 60 символів. Відповідальний: `content`.
Сприймайте цей діапазон як сигнал для перевірки, а не гарантію відображення в
пошуку.

### missing-description

Сторінка не має meta description. Відповідальний: `content`. Додайте корисний
опис там, де важливий текст у результатах пошуку.

### duplicate-description

Кілька сторінок мають однаковий description. Відповідальний: `content`.
Напишіть опис, який відповідає конкретній сторінці.

### description-length

Description коротший за 50 або довший за 160 символів. Відповідальний:
`content`. Перевірте зрозумілість тексту та ймовірність обрізання.

### missing-h1

Заголовок H1 відсутній. Відповідальний: `content`. Додайте чіткий основний
заголовок.

### multiple-h1

На сторінці більше одного H1. Відповідальний: `content`. Це інформаційне
повідомлення: перевірте ієрархію документа, не змінюючи її механічно.

## Посилання, мова, структуровані дані та контент

### broken-internal-link

Внутрішнє посилання веде на проскановану сторінку, яка недоступна або повернула
помилку. Відповідальний: `developer`. Відновіть, оновіть або приберіть
посилання.

### invalid-hreflang

Альтернативна версія має некоректний мовний тег BCP 47 або нерозпізнаний URL.
Відповідальний: `seo`. Виправте мову та цільову адресу.

### invalid-language

Значення мови в `html` не є коректним тегом BCP 47. Відповідальний:
`developer`. Правильно вкажіть мову документа.

### malformed-json-ld

Блок `application/ld+json` не є коректним JSON. Відповідальний: `developer`.
Виправте синтаксис JSON перед перевіркою словника.

### duplicate-content

Нормалізований видимий текст на кількох сторінках має однаковий SHA-256.
Відповідальний: `content`. Об’єднайте точні дублікати або суттєво розрізніть
їхній вміст.

### image-missing-alt

Зображення не має атрибута `alt`. Відповідальний: `content`. Додайте змістовний
альтернативний текст або порожній атрибут для декоративного зображення.

### low-word-count

Сторінка має менше ніж 200 видимих слів. Відповідальний: `content`. Це лише
сигнал для перевірки: лаконічна сторінка може бути цілком доречною.

### missing-open-graph

Відсутні Open Graph title, description або image. Відповідальний: `content`.
Додайте поля, якщо важливий вигляд посилання в соціальних мережах.

### missing-twitter-metadata

Відсутні Twitter card, title, description або image. Відповідальний: `content`.
Додайте поля, якщо важливий вигляд посилання на цій платформі.

## Правила лише для регресій

### robots-changed

Змінився hash вмісту `robots.txt`. Перевірте конкретну зміну в розгортанні.

### page-missing

Сторінку з базового знімка не перевірено в поточному знімку.

### status-regression

Сторінка, яка раніше була доступною, тепер повертає помилковий HTTP-статус.

### new-noindex

Сторінка отримала директиву `noindex` у meta або `X-Robots-Tag`. Це рівень
`error`, оскільки випадкова втрата індексації є ризиком високої критичності.

### title-removed

Title, який раніше був присутній, тепер відсутній.

### title-changed

Title змінився. Перевірте, чи передбачена ця зміна контентом або розгортанням.

### description-removed

Description, який раніше був присутній, тепер відсутній.

### canonical-removed

Canonical, який раніше був присутній, тепер відсутній.

### canonical-changed

Ціль canonical змінилася. Нова ціль на іншому origin підвищує критичність
проблеми до `error`.

### h1-removed

Сторінка, яка мала H1, тепер його не має.

### redirect-changed

Кінцева адреса перенаправлення змінилася. Нова адреса на іншому origin підвищує
критичність проблеми до `error`.
