# SEO Crawl Audit brand

The coral crab is the selected product mark. Its raised claws and scan brackets
connect the crawler identity with inspection. Use the same reviewed PNG in the
website, documentation and native client distributions.

- `logo.png`: unchanged generated master artwork, selected by the project owner.
- `logo-512.png`: production PNG used by client packages and the website.
- `logo-128.png` / `logo-128.jpg`: compact display derivatives; the JPEG is embedded in offline report/UI output.
- Core colors: coral `#f05a40`, orange `#ffa36c`, navy `#14243c`.
- UI background: white `#ffffff` and cool gray `#f2f5f8`.
- Keep the mark visible at small sizes; do not place text inside it or add a
  client platform's logo in a way that suggests official approval.

The master is preserved; copied production package assets share the same reviewed 512px derivative. Its pale
background is part of the selected PNG, not transparency. Automated packaging
checks verify matching bytes and image dimensions. See
[client branding support](../plugin-branding.md) for supported manifest fields
and the distinction between metadata discovery and GUI rendering.
