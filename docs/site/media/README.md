# Reference report media — 0.17.2

These are unretouched browser viewport captures of the actual 0.17.2 interface after the shared design-system update. They show the selected crab, the report engine version and the shipped controls. They do not simulate Codex or Claude plugin picker windows.

## Provenance

All report screenshots use `examples/quotes-toscrape-report.html`, regenerated by `scripts/generate-demo.mjs` with the 0.17.2 core renderer. Its four page records and eight historical runs are deterministic synthetic inputs, not a live audit of quotes.toscrape.com. Counts, dates, regressions and search-visibility states are demonstration data. These report captures were not generated through an MCP scan, so no MCP-action recording is claimed.

The README local-app screenshot separately shows a completed three-page HTTP scan of a controlled loopback fixture. It contains no customer site, credentials, personal path or account data. The reference report may show the public educational quotes domain only as its explicit synthetic example identity.

## Captures

- `native-report-overview.png`: report overview, 1425×990.
- `native-report-pages.png`: Page Explorer with four example pages, 1425×990.
- `native-report-issues.png`: unfiltered issue table with evidence and remediation, 1425×990.
- All six `docs/images/report-*.png` README screenshots are 1425×990: local app, overview, site metrics, pages, analytics and issues. The analytics viewport is deliberately scrolled to its real charts; it has no fabricated header overlay.
- `native-workflow.mp4`: exactly 14 seconds, assembled from four actual browser capture states—overview, pages, site metrics and issues—held for 3.5 seconds each. It is a silent capture sequence, not a continuous screen recording. No simulated UI, compositing, narration or music.
- `native-demo-report.html`: the same regenerated reference report with only noindex/nofollow added for public hosting. `/demo/` and `/report.html` preserve the same reference example under noindex.
- `logo.png`: the existing selected 512px production crab artwork, unchanged in this media refresh.

PNG files are format-only conversions of the browser JPEG captures. No colors, controls, values or logos were redrawn or pasted into them. The video adds at most one pixel of padding for the codec's even-width requirement. GUI plugin installation remains a separate verification gate; report captures do not establish client picker rendering or platform endorsement.
